# CycleArc 0.9.1

## Compact widget status

- Removed the reserved status footer and its gap from each account module, making the widget more compact. Refresh status now uses a small icon in the account header instead of bottom text or empty space.
- A rotating arc shows an active check when no existing warning applies. Previous data, failed checks and account actions use a warning triangle; a retry keeps that warning until success. Other pending or informational states use their own icon, and healthy server data hides the status icon.
- Hover for the full status summary, details, elapsed time, original exact check or receipt time and recovery guidance. Screen readers retain this information. Provider badges remain separate, and quota rings keep their usage colors.
- Status changes and opening a tooltip keep the widget's height and position stable. Changing the number of accounts or displayed quota rows can still change its layout.

Download `CycleArc-Setup.exe` for Windows x64. Existing installed releases can use **Check for updates → Download update → Restart & update**. Accounts, preferences and quota caches remain in `%LOCALAPPDATA%\ProMeter`.

## 간결한 위젯 상태 표시

- 계정 모듈마다 예약하던 하단 상태 공간과 간격을 제거해 위젯을 더 작게 만들었습니다. 갱신 상태는 하단 문구나 빈 공간 대신 계정 헤더의 작은 아이콘으로 표시합니다.
- 기존 경고가 없는 조회 중에는 회전하는 호를 표시합니다. 이전 데이터·조회 실패·계정 조치 필요 상태는 경고 삼각형으로 표시하며, 재시도 중에도 성공할 때까지 경고를 유지합니다. 그 밖의 대기·안내 상태는 해당 아이콘으로 표시하고, 정상 서버 데이터에서는 상태 아이콘을 숨깁니다.
- 마우스를 올리면 전체 상태 요약, 상세 설명, 경과 시간, 원래의 정확한 확인·수신 시각과 복구 안내를 볼 수 있습니다. 화면 읽기 프로그램에도 이 정보를 유지합니다. 서비스 배지는 상태 아이콘과 구분하고, 사용량 링은 사용률에 따른 색을 유지합니다.
- 상태가 바뀌거나 툴팁을 열어도 위젯 높이와 위치를 유지합니다. 계정 수나 표시하는 한도 행 수가 바뀌면 배치는 달라질 수 있습니다.

Windows x64용 `CycleArc-Setup.exe`를 다운로드하세요. 기존 설치형 버전에서는 **업데이트 확인 → 업데이트 다운로드 → 재시작 후 적용**을 사용할 수 있습니다. 계정·설정·사용량 캐시는 `%LOCALAPPDATA%\ProMeter`에 유지됩니다.
