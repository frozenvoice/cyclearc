# CycleArc 0.10.0

## Clearer controls and lighter background work

- Migrated to .NET 10 LTS. The Windows x64 installer continues to include the app runtime.
- Simplified the detail popup header with compact status indicators and direct pin/unpin and Close controls.
- Added the current zoom percentage and clearer zoom buttons to the detail popup and floating widget.
- Fixed multi-account widget clipping at high DPI.
- Reduced unnecessary work in hidden popups, account rows, tray icon redraws and refresh animations, and reduced allocations when reading Claude Desktop usage history.
- Simplified quota controls and missing-credit presentation, keeping usage views focused on current limits and remaining allowance.
- Improved source-build prerequisite preparation, desktop shutdown before installation and failure diagnostics.

Download `CycleArc-Setup.exe` for Windows x64. Existing installed releases can use **Check for updates → Download update → Restart & update**. Accounts, preferences and quota caches remain in `%LOCALAPPDATA%\ProMeter`.

## 더 명확한 조작과 백그라운드 작업 개선

- .NET 10 LTS로 전환했습니다. Windows x64 설치 프로그램에는 앱 실행에 필요한 런타임이 계속 포함됩니다.
- 상세 팝업 헤더의 상태 표시를 간결하게 정리하고, 고정/고정 해제와 닫기 버튼을 바로 사용할 수 있게 했습니다.
- 상세 팝업과 플로팅 위젯에 현재 확대 비율을 표시하고 확대 버튼을 명확하게 했습니다.
- 높은 DPI에서 여러 계정 위젯이 잘리는 문제를 수정했습니다.
- 숨겨진 팝업, 계정 목록, 트레이 아이콘 다시 그리기와 새로고침 애니메이션의 불필요한 작업을 줄이고, Claude Desktop 사용량 기록을 읽을 때 메모리 할당을 줄였습니다.
- 한도 조작과 크레딧 정보가 없을 때의 표시를 정리하고, 사용량 화면을 현재 한도와 남은 사용량 중심으로 구성했습니다.
- 소스 빌드의 필수 구성요소 준비, 설치 전 앱 종료 처리와 오류 진단을 개선했습니다.

Windows x64용 `CycleArc-Setup.exe`를 다운로드하세요. 기존 설치형 버전에서는 **업데이트 확인 → 업데이트 다운로드 → 재시작 후 적용**을 사용할 수 있습니다. 계정·설정·사용량 캐시는 `%LOCALAPPDATA%\ProMeter`에 유지됩니다.
