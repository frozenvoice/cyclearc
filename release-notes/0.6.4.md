# CycleArc 0.6.4

## Popup and widget redesign

- The popup now opens on the selected account: its ring, the limit that ring shows and its reset come first, with every other reported limit and the check time in full-width rows below. The account list follows in your saved order, and selecting an account highlights it in place instead of moving it.
- Rings in the popup and widget now fill with what is **left** and are labeled that way, for example **Weekly left 86%**. The exact used percentage stays in the quota rows and tooltips. Colors still follow actual usage (blue, amber from 70%, orange from 85%, red at 100%); an exhausted limit shows an empty ring labeled **Limit reached**, and an unknown value stays **?** without a fill. The tray keeps showing usage.
- Popup account rows show each reported limit as a bar filled with what is left, aligned across all accounts, with the value at popup precision and the full used/left pair in the row tooltip. A healthy server check no longer repeats **Updated** on every row; received samples, stale data and sign-in problems are still named.
- Reset credits fold into one line with the count and the nearest expiry; expand it to see each credit and **Use reset**. The list is only as tall as its credits.
- The Claude card shows its shared Web·Desktop·Code scope and the usage page on one line. A healthy server check keeps its update sentence in that line's tooltip and its time in **Last checked**.
- The popup and widget share a darker background, and header icons rest without boxes; zoom, refresh, settings, pin and close are unchanged.
- Widget: limits outside the ring get the same small remaining bar for every provider, including Cursor percentage allowances. The opacity setting now fades only the widget background, so names, numbers and rings stay fully legible; new installations start fully opaque.

## Screen-edge snapping across monitors

- Dragging the widget partly past the outer edge of a monitor no longer makes it reappear on another display. A drop now stays on the monitor where you release the mouse.
- Pushing the widget or detail popup past a screen edge attaches it to that edge with the usual 2-DIP inset, instead of leaving it slightly away from the edge. Dropping near an edge, **Shift** to skip snapping and the setting to turn it off are unchanged.
- A restored detail popup that spans two monitors returns to the one holding most of it.

Download `CycleArc-Setup.exe` for Windows x64. Existing installed releases can use **Check for updates → Download update → Restart & update**. Accounts, preferences and quota caches remain in `%LOCALAPPDATA%\ProMeter`.

## 팝업·위젯 디자인 개선

- 팝업이 선택 계정부터 보여줍니다. 링과 링이 표시하는 한도·리셋이 맨 위에 오고, 나머지 한도와 확인 시각은 아래에 전체 폭으로 표시합니다. 계정 목록은 저장된 순서를 유지하며, 계정을 선택하면 자리 이동 없이 강조만 됩니다.
- 팝업·위젯의 링은 **남은 양**만큼 채워지고 **주간 남음 86%**처럼 표시됩니다. 정확한 사용률은 한도별 행과 툴팁에 남습니다. 색은 계속 실제 사용률을 따르며(파랑, 70% 이상 앰버, 85% 이상 주황, 100% 빨강), 모두 소진된 한도는 빈 링에 **소진**, 알 수 없는 값은 채움 없이 **?**로 표시합니다. 트레이는 계속 사용률을 표시합니다.
- 팝업 계정 행은 한도마다 남은 만큼 채운 막대를 모든 계정에서 같은 위치에 정렬해 표시하고, 상세 정밀도의 남은 값과 사용·잔여 전체 값(툴팁)을 보여줍니다. 정상 서버 조회는 행마다 **업데이트됨**을 반복하지 않으며, 수신값·오래된 데이터·로그인 문제는 계속 표시합니다.
- 리셋권은 보유 수와 가장 빠른 만료만 한 줄로 접어 두고, 펼치면 리셋권별 만료와 **초기화 사용**이 나옵니다. 목록은 리셋권 수만큼만 높아집니다.
- Claude 카드는 Web·Desktop·Code 공유 한도 설명과 사용량 페이지 링크를 한 줄로 표시합니다. 정상 서버 조회의 업데이트 문장은 그 줄의 툴팁으로, 시각은 **마지막 확인**으로 옮겼습니다.
- 팝업과 위젯이 더 어두운 같은 바탕을 쓰고, 헤더 아이콘은 평소 배경 상자 없이 표시합니다. 확대·축소, 새로고침, 설정, 고정, 닫기는 그대로입니다.
- 위젯: 링에 없는 한도에는 Cursor 퍼센트 한도를 포함해 모든 제공자에서 같은 작은 잔여 막대를 붙입니다. 투명도 설정은 이제 위젯 배경에만 적용되어 이름·숫자·링은 항상 선명하며, 새로 설치하면 완전히 불투명한 상태로 시작합니다.

## 여러 모니터에서 화면 가장자리 정렬

- 위젯을 모니터 바깥쪽 가장자리 밖으로 조금 밀어 놓아도 다른 모니터에 나타나지 않습니다. 마우스를 놓은 모니터에 그대로 남습니다.
- 위젯이나 상세 팝업을 화면 가장자리 밖으로 밀어 놓으면 가장자리에서 조금 떨어진 채 남지 않고, 기존처럼 2 DIP 안쪽으로 붙습니다. 가장자리 근처에 놓았을 때의 정렬, **Shift**로 정렬 생략, 설정에서 끄기는 그대로입니다.
- 두 모니터에 걸쳐 있던 상세 팝업은 복원할 때 더 많이 걸친 모니터로 돌아갑니다.

Windows x64용 `CycleArc-Setup.exe`를 다운로드하세요. 기존 설치형 버전에서는 **업데이트 확인 → 업데이트 다운로드 → 재시작 후 적용**을 사용할 수 있습니다. 계정·설정·사용량 캐시는 `%LOCALAPPDATA%\ProMeter`에 유지됩니다.
