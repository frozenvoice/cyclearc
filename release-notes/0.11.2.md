# CycleArc 0.11.2

## A redesigned installer and neutral dark theme

- `CycleArc-Setup.exe` has a new compact dark window with rounded corners, a soft glow along the bottom edge, large status text and a thin progress bar. It still asks before installing, shows the installation location and the desktop shortcut option, and lets you choose **Run CycleArc** before **Finish**.
- While installing, the window names the step in progress. If installation fails, it shows the installer log location and the cause as copyable text, and does not start CycleArc.
- The installer follows Windows high contrast and the **Animation effects** setting, and scales cleanly when moved between monitors with different display scaling.
- The app's dark theme now uses neutral grays instead of a blue-tinted navy for backgrounds, cards, panels and lines. Accent and provider colors and the light theme are unchanged.

Installation locations, updates, desktop shortcut handling and your data in `%LOCALAPPDATA%\ProMeter` are unchanged.

## 새 설치 창과 중립 다크 테마

- `CycleArc-Setup.exe`가 둥근 모서리, 하단의 은은한 빛 번짐, 큰 상태 문구와 얇은 진행 막대를 갖춘 새 다크 설치 창으로 바뀌었습니다. 설치 전 확인, 설치 위치, 바탕화면 바로가기 선택, **완료** 전 **CycleArc 실행** 선택은 그대로입니다.
- 설치 중에는 진행 중인 단계를 보여 줍니다. 설치에 실패하면 설치 로그 위치와 원인을 복사할 수 있는 텍스트로 보여 주며 CycleArc를 실행하지 않습니다.
- Windows 고대비와 **애니메이션 효과** 설정을 따르고, 배율이 다른 모니터로 옮겨도 선명하게 다시 그립니다.
- 앱의 다크 테마 배경·카드·패널·구분선이 푸른빛 남색 대신 중립 회색을 사용합니다. 강조색, 서비스별 색상과 라이트 테마는 바뀌지 않았습니다.

설치 위치, 업데이트, 바탕화면 바로가기 처리와 `%LOCALAPPDATA%\ProMeter`의 데이터는 그대로 유지됩니다.
