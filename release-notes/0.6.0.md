# CycleArc 0.6.0

## Windows installer and in-app updates

- Install once with `CycleArc-Setup.exe`. CycleArc appears in the Start menu and Windows installed apps.
- Check for updates from the tray menu or About. Installed releases also check after startup and every six hours.
- Review the version and release notes, download the update, then choose **Restart & update** when ready. **Later** keeps the current version running; closing a download cancels it.
- Only published stable releases are offered. Downloaded full packages are checked with SHA-256 before they are accepted and again before application.
- A verified external copy restores the previous version if replacement or initial desktop startup fails. A blocked recovery preserves the backup and shows its location.
- Existing accounts, preferences and usage caches remain in `%LOCALAPPDATA%\ProMeter`. Existing CycleArc-owned Claude callbacks move to the installed application's stable path after the connected identity is verified.
- Headless Claude callbacks do not open update windows or trigger installation. Loose development builds do not check for application updates.

Users of 0.5.x should run the installer once to move to this update flow. Keep the previous executable until the new installation has successfully verified and migrated your Claude connection.

## Windows 설치 프로그램과 앱 내 업데이트

- `CycleArc-Setup.exe`로 한 번 설치하면 시작 메뉴와 Windows 설치된 앱 목록에서 사용할 수 있습니다.
- 트레이 메뉴 또는 정보 화면에서 업데이트를 확인할 수 있으며, 설치형 버전은 시작 후와 6시간마다 새 버전을 확인합니다.
- 버전과 변경 내용을 확인하고 다운로드한 뒤 **재시작 후 적용**을 선택하세요. **나중에**를 누르면 현재 버전을 계속 사용하고, 다운로드 중 창을 닫으면 취소됩니다.
- 공개된 정식 릴리스만 제공하며, 전체 패키지의 SHA-256을 다운로드 완료 후와 적용 직전에 확인합니다.
- 파일 교체나 새 앱 시작에 실패하면 검증된 외부 사본으로 이전 버전을 복구합니다. 복구가 막힌 경우에도 백업을 보존하고 위치를 안내합니다.
- 기존 계정·설정·사용량 캐시는 `%LOCALAPPDATA%\ProMeter`에 유지됩니다. 기존 Claude 연결은 계정 신원을 확인한 후 설치된 앱의 고정 경로로 이전합니다.
- Claude 수신기가 업데이트 창을 띄우거나 설치를 시작하지 않습니다. 개발용 단독 실행 파일은 앱 업데이트를 확인하지 않습니다.

0.5.x 사용자는 설치 프로그램을 한 번 실행하면 새 업데이트 방식으로 전환됩니다. Claude 연결 이전이 확인될 때까지 이전 실행 파일을 유지하세요.
