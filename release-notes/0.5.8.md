# CycleArc 0.5.8

- Downloads and development builds now share one per-user installation path and tray identity.
- A second ordinary launch opens the first running instance and displays its version. Automatic startup stays quiet.
- About → Install another version and dev-run validate the candidate before switching, wait for shutdown, and restore the prior installed executable if startup fails.
- Verified obsolete tray entries are backed up and removed after the installed tray icon is ready.
- Existing settings, accounts and Claude callbacks retain their compatibility paths.

## 한국어

- 개발용과 릴리즈가 각 PC의 `%LOCALAPPDATA%\Programs\CycleArc`를 함께 사용합니다.
- 일반 중복 실행은 먼저 실행된 앱의 창과 버전을 표시합니다. 자동 시작은 창을 띄우지 않습니다.
- 정보 → 다른 버전 설치 또는 dev-run 실행 시 검증 후 전환하고, 새 앱 시작에 실패하면 이전 설치본을 복구합니다.
- 확인된 이전 트레이 항목은 백업 후 정리하며 기존 계정·설정과 Claude 콜백은 유지합니다.
