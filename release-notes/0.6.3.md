# CycleArc 0.6.3

## Usage ring color bands

- Usage rings on the popup, tray and desktop widget now change color with the actual usage of the limit they show: blue below 70%, amber from 70%, orange from 85% and red from 100%. Accounts close to their limit stand out at a glance, whether or not they are selected.
- Colors use the unrounded percentage. A value such as 99.6% can read **100** in the tray but stays orange and is not treated as used up.
- Each ring follows only its own limit; it is never colored by another limit or combined with it. Stale data, unknown values and sign-in problems keep their existing appearance.
- Tooltips and screen readers add **Caution**, **Near limit** or **Limit reached**. Numbers, text and the selection border are unchanged. The colors are tuned for both Dark and Light themes.
- The English and Korean README guides include ring color screenshots rendered with synthetic sample accounts.

Download `CycleArc-Setup.exe` for Windows x64. Existing installed releases can use **Check for updates → Download update → Restart & update**. Accounts, preferences and quota caches remain in `%LOCALAPPDATA%\ProMeter`.

## 사용률 링 구간별 색상

- 팝업·트레이·데스크톱 위젯의 사용률 링이 표시 중인 한도의 실제 사용률에 따라 색이 바뀝니다. 70% 미만은 파랑, 70% 이상은 앰버, 85% 이상은 주황, 100% 이상은 빨강입니다. 선택 여부와 관계없이 한도에 가까운 계정을 한눈에 알아볼 수 있습니다.
- 색상은 반올림 전 사용률을 기준으로 합니다. 99.6%는 트레이에 **100**으로 보일 수 있지만 주황으로 표시하며 소진으로 처리하지 않습니다.
- 각 링은 자신이 표시하는 한도만 따르며, 다른 한도와 합산하거나 다른 한도의 색을 쓰지 않습니다. 이전 데이터, 알 수 없는 값, 로그인 문제는 기존 표시를 유지합니다.
- 툴팁과 화면 읽기 프로그램에 **주의**, **소진 임박**, **소진**이 덧붙습니다. 숫자·텍스트·선택 테두리는 그대로이며, 다크·라이트 테마 모두에서 구별되도록 색을 맞췄습니다.
- 한·영 README에 가상 샘플 계정으로 렌더링한 링 색상 스크린샷을 추가했습니다.

Windows x64용 `CycleArc-Setup.exe`를 다운로드하세요. 기존 설치형 버전에서는 **업데이트 확인 → 업데이트 다운로드 → 재시작 후 적용**을 사용할 수 있습니다. 계정·설정·사용량 캐시는 `%LOCALAPPDATA%\ProMeter`에 유지됩니다.
