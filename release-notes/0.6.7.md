# CycleArc 0.6.7

## Usage credits, extra usage and on-demand

- The selected account's detail popup adds a folded **Usage credits** (Codex), **Extra usage** (Claude) or **On-demand** (Cursor) card. Expand it for the reported balance or spend and cap, the remaining allowance and the original check time. Each account remembers whether its card is open.
- Off, zero, unlimited and not-provided states are named explicitly. Codex usage credits stay separate from reset credits, and the account list, widget and tray gain no money rows or alerts.

## Widget

- Codex, Claude and Cursor now show the same warning for stale data, failed checks and account actions, while keeping each source's original check or receipt time. Ring colors still follow usage.
- The selected account is now marked with a slightly lifted surface and a short blue marker instead of a long blue line that read like a divider. Blue stays reserved for usage rings and bars, other accounts keep full contrast, and pointing at a module lifts it slightly.

## Settings

- New **Apply** button: changes take effect while Settings stays open, so you can check the widget, tray and popup before closing. It is available only while something has changed.
- Dragging the widget **Opacity** slider previews it on the widget immediately; closing without applying returns to the applied opacity. The slider's lowest setting now matches the widget's 30% floor.

Download `CycleArc-Setup.exe` for Windows x64. Existing installed releases can use **Check for updates → Download update → Restart & update**. Accounts, preferences and quota caches remain in `%LOCALAPPDATA%\ProMeter`.

## 사용 크레딧·추가 사용·온디맨드

- 선택한 계정의 상세 팝업에 접힌 **사용 크레딧**(Codex), **추가 사용**(Claude), **온디맨드**(Cursor) 카드가 추가됩니다. 펼치면 보고된 잔액 또는 사용액과 한도, 남은 허용량, 원래 확인 시각을 볼 수 있으며, 카드를 펼쳤는지는 계정마다 기억합니다.
- 꺼짐·0·무제한·제공되지 않음 상태는 그대로 이름을 붙여 표시합니다. Codex 사용 크레딧은 리셋권과 따로 표시하며, 계정 목록·위젯·트레이에는 금액 행이나 알림을 추가하지 않습니다.

## 위젯

- Codex·Claude·Cursor 모두 오래된 데이터, 조회 실패, 계정 조치 필요 상태를 같은 경고로 표시하며, 각 소스의 원래 확인·수신 시각은 유지합니다. 링 색상은 계속 사용률을 따릅니다.
- 선택한 계정을 구분선처럼 보이던 긴 파란 선 대신 한 단계 밝은 배경과 짧은 파란 표시로 나타냅니다. 파란색은 사용량 링·막대에 남겨 두고, 다른 계정은 흐리게 하지 않으며, 마우스를 올린 모듈은 살짝 밝아집니다.

## 설정

- 새 **적용** 버튼: 설정 창을 연 채로 변경 사항을 반영하므로 닫기 전에 위젯·트레이·팝업을 확인할 수 있습니다. 바뀐 항목이 있을 때만 누를 수 있습니다.
- 위젯 **불투명도** 슬라이더를 움직이면 위젯에 바로 미리 보이며, 적용하지 않고 닫으면 적용된 값으로 돌아갑니다. 슬라이더 최솟값을 위젯의 최소 불투명도 30%에 맞췄습니다.

Windows x64용 `CycleArc-Setup.exe`를 다운로드하세요. 기존 설치형 버전에서는 **업데이트 확인 → 업데이트 다운로드 → 재시작 후 적용**을 사용할 수 있습니다. 계정·설정·사용량 캐시는 `%LOCALAPPDATA%\ProMeter`에 유지됩니다.
