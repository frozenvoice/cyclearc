# CycleArc 0.6.2

## Cursor support and build improvements

- Connect the account signed in to the Windows Cursor app from **Manage accounts → Add an account → Connect Cursor**. CycleArc verifies the account before showing its usage and keeps Codex, Claude and Cursor profiles separate. No token copying is needed.
- View **Cursor Models · Monthly**, **Other Models · Monthly** and **Grok Bot · Weekly** in the popup, tray and desktop widget. On-demand budgets stay separate, missing values remain unknown, and failed checks retain the last successful values with their original update time.
- The Cursor widget shows up to three reported allowances with a named usage ring and a compact update age. Tray digits round fractional usage to whole percentages while details keep decimal precision. Widget account modules align across providers, with improved recovery on monitors using different display scales.
- Updated the app and installer icon. The English and Korean README guides include Cursor connection instructions and screenshots of the actual popup and widget using synthetic accounts.
- Local source builds check the installer toolchain before building and offer to install missing Visual Studio 2022 C++ prerequisites with approval. Local and Windows CI verification now use the same fail-fast gate, with corrected package checks and installer artifact upload.

Download `CycleArc-Setup.exe` for Windows x64. Existing installed releases can use **Check for updates → Download update → Restart & update**. Accounts, preferences and quota caches remain in `%LOCALAPPDATA%\ProMeter`.

## Cursor 지원과 빌드 개선

- **계정 관리 → 계정 추가 → Cursor 연결**에서 Windows Cursor 앱의 현재 로그인 계정을 연결할 수 있습니다. 계정 확인 후 사용량을 표시하며 Codex·Claude·Cursor 프로필을 각각 유지합니다. 토큰을 복사할 필요가 없습니다.
- 팝업·트레이·데스크톱 위젯에서 **Cursor Models · 월간**, **Other Models · 월간**, **Grok Bot · 주간**을 확인할 수 있습니다. 추가 사용 예산은 별도로 표시하고, 제공되지 않은 값은 미확인으로 유지합니다. 조회에 실패하면 마지막 정상값과 당시 확인 시각을 유지합니다.
- Cursor 위젯에 제공된 한도를 최대 세 개까지 표시하고, 사용률 링의 한도 이름과 짧은 갱신 경과 시간을 보여줍니다. 트레이 숫자는 정수로 반올림하고 상세 화면에는 소수점을 유지합니다. 서비스별 위젯 계정 모듈을 정렬하고, 화면 배율이 다른 모니터 사이의 위치 복구를 개선했습니다.
- 앱과 설치 프로그램 아이콘을 갱신했습니다. 한·영 README에 Cursor 연결 방법과 가상 계정을 사용한 실제 팝업·위젯 스크린샷을 포함했습니다.
- 로컬 소스 빌드는 시작 전에 설치 프로그램용 도구를 검사하고, Visual Studio 2022 C++ 필수 구성요소가 없으면 동의를 받아 설치하도록 안내합니다. 로컬과 Windows CI가 같은 검증 절차를 사용하도록 통합하고 패키지 검사와 설치 파일 업로드를 수정했습니다.

Windows x64용 `CycleArc-Setup.exe`를 다운로드하세요. 기존 설치형 버전에서는 **업데이트 확인 → 업데이트 다운로드 → 재시작 후 적용**을 사용할 수 있습니다. 계정·설정·사용량 캐시는 `%LOCALAPPDATA%\ProMeter`에 유지됩니다.
