# CycleArc 0.12.0

## Cursor ring follows your last request

- The Cursor ring now shows the pool your most recent Cursor request used. A Claude, GPT or Gemini request moves it to **Other Models**; a Composer request moves it to **Cursor Models**. Auto and unrecognized models leave the ring where it was.
- The ring only follows a request when the Cursor hook is connected, the account is verified and the request is at most 12 hours old. The popup, widget and tray icon use the same rule, and the tooltip names the model, when the request was seen and which limit is shown. This is a display hint, not a billing record.
- Cursor reconnects again after Cursor began storing its local sign-in token in encrypted form. CycleArc decrypts it only in memory and still never reads the refresh token.
- A brief file lock or read error no longer clears the last Cursor request or other accounts' entries.

## Fixes

- When a Claude reset time has passed and no new one has been reported yet, CycleArc shows **Next reset unconfirmed** (**Reset unconfirmed** in the widget) instead of counting down from a stale time. The countdown returns as soon as Claude reports a new reset.
- The widget grows when Cursor adds a Grok Bot row, so the row is no longer cut off at the bottom.
- The widget no longer resizes itself when only display-scaling rounding changed.

Installation locations, updates, desktop shortcut handling and your data in `%LOCALAPPDATA%\ProMeter` are unchanged.

## Cursor 링이 마지막 요청을 따라갑니다

- Cursor 링이 가장 최근 Cursor 요청이 쓴 한도를 보여 줍니다. Claude·GPT·Gemini 요청은 **Other Models**로, Composer 요청은 **Cursor Models**로 링을 옮깁니다. Auto와 알 수 없는 모델은 링을 바꾸지 않습니다.
- Cursor 훅이 연결되어 있고, 계정이 확인되었으며, 요청이 12시간 이내일 때만 링이 따라갑니다. 팝업, 위젯, 트레이 아이콘이 같은 규칙을 쓰며, 툴팁에 모델, 요청을 확인한 시각, 표시 중인 한도를 보여 줍니다. 결제 기록이 아닌 표시용 안내입니다.
- Cursor가 로컬 로그인 토큰을 암호화해 저장하기 시작한 뒤에도 다시 연결할 수 있습니다. CycleArc는 이 값을 메모리에서만 풀며, 리프레시 토큰은 여전히 읽지 않습니다.
- 잠깐의 파일 잠금이나 읽기 오류로 마지막 Cursor 요청이나 다른 계정 기록이 지워지지 않습니다.

## 수정 사항

- Claude 리셋 시각이 지났는데 새 시각이 아직 오지 않았으면, 지난 시각으로 카운트다운하지 않고 **다음 리셋 시각 미확인**(위젯은 **리셋 미확인**)으로 표시합니다. Claude가 새 리셋 시각을 알려 주면 바로 카운트다운으로 돌아갑니다.
- Cursor에 Grok Bot 줄이 추가되면 위젯 창도 커져서 아래쪽이 잘리지 않습니다.
- 디스플레이 배율 반올림만 달라졌을 때 위젯이 스스로 크기를 바꾸지 않습니다.

설치 위치, 업데이트, 바탕화면 바로가기 처리와 `%LOCALAPPDATA%\ProMeter`의 데이터는 그대로 유지됩니다.
