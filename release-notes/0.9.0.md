# CycleArc 0.9.0

## Current release

This release brings the current CycleArc feature set together under version 0.9.0.

- Monitor multiple **Codex, Claude and Cursor** accounts from the Windows tray, detail popup and optional desktop widget. Each account keeps its own reported limits, remaining percentages, reset times and refresh state.
- Codex includes reported reset credits and a separate **Credit balance** card. Claude provides **Extra usage**, and Cursor provides **On-demand** details. These folded cards show reported amounts, allowances and check times without adding money rows to the widget or tray; missing, zero, off and unlimited values remain distinct.
- Choose usage or remaining numbers in the tray, compare accounts side by side in the widget, and receive Windows usage alerts at 85% and exhaustion. Alerts retain their per-account, per-limit period history across refreshes and restarts.
- Use English or Korean, System/Light/Dark themes, separate popup and widget zoom, and widget opacity. **Apply** changes settings while the window stays open; the opacity slider previews changes immediately.

## Latest improvements

- The widget reserves two lines for its refresh status and timestamp. Checking, retry, failure and recovery messages can appear or disappear without changing its height. Healthy server data hides the content while retaining the space; warning colors and original check or receipt times remain visible when needed.
- The installer offers an optional **Create a desktop shortcut** checkbox. It starts unchecked for a new installation; reinstalling reflects the existing shortcut. Updates and silent reinstalls preserve the choice, and the Start menu entry remains available.
- Codex's monetary card is named **Credit balance** to make it easier to distinguish from reset credits. Provider-specific amounts and units remain separate from quota percentages.

Download `CycleArc-Setup.exe` for Windows x64. Existing installed releases can use **Check for updates → Download update → Restart & update**. Accounts, preferences and quota caches remain in `%LOCALAPPDATA%\ProMeter`.

## 현재 릴리즈

현재 CycleArc의 기능을 버전 0.9.0으로 모은 릴리즈입니다.

- Windows 트레이, 상세 팝업과 선택형 바탕화면 위젯에서 여러 **Codex·Claude·Cursor** 계정을 확인합니다. 계정마다 보고된 한도, 남은 비율, 리셋 시각과 갱신 상태를 따로 유지합니다.
- Codex는 제공된 리셋권과 별도의 **크레딧 잔액** 카드를 표시합니다. Claude는 **추가 사용**, Cursor는 **온디맨드** 정보를 제공합니다. 접힌 카드를 펼치면 보고된 금액·허용량·확인 시각을 볼 수 있으며, 위젯·트레이에 금액 행을 추가하지 않습니다. 제공되지 않음·0·꺼짐·무제한은 구분해 표시합니다.
- 트레이에서 사용률 또는 남은 양 숫자를 고르고, 위젯에서 계정을 나란히 비교하며, 사용률 85%와 소진 시 Windows 알림을 받습니다. 계정·한도별 기간 내 알림 기록은 새로고침과 재시작 뒤에도 유지합니다.
- 한국어·영어, 시스템·라이트·다크 테마, 팝업·위젯별 확대 배율과 위젯 불투명도를 지원합니다. **적용**으로 설정 창을 연 채 변경 사항을 반영하고, 불투명도 슬라이더는 움직이는 동안 바로 미리 보여 줍니다.

## 최신 개선 사항

- 위젯의 갱신 상태와 시각에 두 줄 공간을 확보했습니다. 조회 중·재시도·실패·복구 문구가 나타나거나 사라져도 위젯 높이가 바뀌지 않습니다. 정상 서버 데이터에서는 내용만 숨기고 공간은 유지하며, 필요한 경고 색상과 원래 확인·수신 시각은 표시합니다.
- 설치기에 선택형 **바탕화면 바로가기 만들기** 항목이 있습니다. 새 설치에서는 기본으로 꺼져 있고, 재설치에서는 기존 바로가기 상태를 반영합니다. 업데이트와 자동 재설치는 선택을 유지하며, 시작 메뉴 항목은 계속 제공됩니다.
- Codex의 금액 카드를 **크레딧 잔액**으로 표시해 리셋권과 쉽게 구분할 수 있습니다. 제공자별 금액과 단위는 사용 한도 퍼센트와 따로 유지합니다.

Windows x64용 `CycleArc-Setup.exe`를 다운로드하세요. 기존 설치형 버전에서는 **업데이트 확인 → 업데이트 다운로드 → 재시작 후 적용**을 사용할 수 있습니다. 계정·설정·사용량 캐시는 `%LOCALAPPDATA%\ProMeter`에 유지됩니다.
