# CycleArc 0.6.1

## Multi-account widget and installation improvements

- Compare Codex and Claude accounts side by side in the desktop widget, with each account's quota periods, remaining percentages, reset countdowns and refresh state. Select an account to open its details; refresh all accounts from the widget header.
- Resize the popup and widget independently with their header buttons or `Ctrl` + `+` / `Ctrl` + `-`. Each window remembers its size. Clicking the widget header gives it keyboard focus without opening the popup.
- Keep the widget on the monitor where you placed it, with improved layout, scrolling and recovery across display scales and monitor changes.
- The Windows installer now shows confirmation, progress and completion, with a choice to run CycleArc when installation finishes. A fresh install uses `%LOCALAPPDATA%\Programs\CycleArc`; existing installations retain their location and account data.
- Removing the installed app cleans up its own Claude callbacks while preserving unrelated Claude configuration and CycleArc account/settings data. Same-version repair waits for the existing desktop to release the installation.
- The Settings window opens with its complete General tab visible. Local source builds have a checked `build-local.cmd` entry point, clearer progress and retained failure logs.
- Updated the English and Korean guides and update previews to match the current controls, connection flow and installer behavior.

Download `CycleArc-Setup.exe` for Windows x64. Existing installed releases can use **Check for updates → Download update → Restart & update**. Accounts, preferences and quota caches remain in `%LOCALAPPDATA%\ProMeter`.

## 다중 계정 위젯과 설치 개선

- 데스크톱 위젯에서 Codex와 Claude 계정별 사용 기간, 남은 비율, 초기화 카운트다운과 갱신 상태를 나란히 비교할 수 있습니다. 계정을 누르면 상세 화면이 열리고, 위젯 상단에서 전체 계정을 새로고침할 수 있습니다.
- 팝업과 위젯의 상단 버튼 또는 `Ctrl` + `+` / `Ctrl` + `-`로 각 창의 크기를 따로 조절하고 저장합니다. 위젯 상단을 누르면 팝업을 열지 않고 키보드 초점을 받습니다.
- 위젯을 놓은 모니터를 유지하며 화면 배율과 모니터 변경에 따른 배치, 스크롤, 위치 복구를 개선했습니다.
- Windows 설치 프로그램에 확인·진행·완료 화면과 설치 후 실행 선택이 추가되었습니다. 새 설치는 `%LOCALAPPDATA%\Programs\CycleArc`를 사용하고, 기존 설치는 원래 위치와 계정 데이터를 유지합니다.
- 앱 제거 시 해당 설치가 소유한 Claude 콜백을 정리하며, 다른 Claude 설정과 CycleArc 계정·설정 데이터는 보존합니다. 같은 버전 복구 설치는 기존 앱이 설치 파일 사용을 끝낼 때까지 기다립니다.
- 설정 창을 열면 일반 탭의 내용이 모두 보이도록 수정했습니다. 소스 빌드용 `build-local.cmd`의 실행 검사, 진행 표시와 실패 로그 보존도 개선했습니다.
- 한·영 안내와 업데이트 미리보기를 현재 조작 방식, 연결 흐름, 설치 동작에 맞춰 갱신했습니다.

Windows x64용 `CycleArc-Setup.exe`를 다운로드하세요. 기존 설치형 버전에서는 **업데이트 확인 → 업데이트 다운로드 → 재시작 후 적용**을 사용할 수 있습니다. 계정·설정·사용량 캐시는 `%LOCALAPPDATA%\ProMeter`에 유지됩니다.
