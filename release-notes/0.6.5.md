# CycleArc 0.6.5

## Usage alerts

- CycleArc now sends a Windows notification the first time in a period that an account's limit reaches 85% used, and again when it is used up. Each account and limit is announced once per period, across refreshes and restarts; stale or unknown values never alert. Click the notification to open that account.
- Alerts are on by default. Turn them off in **Settings → Connection → Usage alerts**.

## Tray: left number

- A new **Left number** tray style shows what is left of the selected limit (**33** means **33% left**), matching the popup and widget rings. **Usage number** remains the default.

## Clearer status and wording

- The popup header now reads **All updated** when a Claude account was checked on the server; **Received** appears only while a Claude Code statusLine or Desktop history sample is shown.
- A Claude profile that was never connected shows **Not connected** and points to **Connect**, instead of asking for a Desktop sign-in and refresh that cannot help. A connected profile's button reads **Connection**.
- What is left reads **Left** everywhere, including Cursor allowances. Cursor resets are named and counted down under each value, and every provider shows its check time in the same **Last checked** row, with the date only when it is not today.
- While awaiting usage, the popup explains its empty ring side and keeps the long notice to one line in the account list. Claude Desktop history samples no longer show a **Not available** reset row per limit; their notice says that source has no reset times.
- Scroll bars follow the dark and light themes in every window, including account management, the Claude connection window and updates.
- The popup shows the release version (**Version 0.6.5**), reset credits read **Expires …**, the Claude connection window gives its Desktop guidance once, and the widget ring caption is easier to read.

Download `CycleArc-Setup.exe` for Windows x64. Existing installed releases can use **Check for updates → Download update → Restart & update**. Accounts, preferences and quota caches remain in `%LOCALAPPDATA%\ProMeter`.

## 사용량 알림

- 계정의 한도가 한 기간 안에서 처음 85% 사용에 닿을 때와 모두 사용했을 때 Windows 알림을 보냅니다. 계정·한도마다 기간당 한 번씩만 알리며 새로고침이나 재시작으로 반복하지 않고, 오래된 값이나 알 수 없는 값으로는 알리지 않습니다. 알림을 누르면 그 계정을 엽니다.
- 기본으로 켜져 있으며 **설정 → 연결 → 사용량 알림**에서 끌 수 있습니다.

## 트레이: 남은 양 숫자

- 새 트레이 스타일 **남은 양 숫자**는 팝업·위젯 링처럼 선택한 한도의 남은 양을 표시합니다(**33**은 **33% 남음**). 기본값은 계속 **사용률 숫자**입니다.

## 상태와 문구 정리

- Claude 계정을 서버에서 확인했으면 팝업 상단이 **전체 최신**으로 표시됩니다. **수신값 포함**은 Claude Code statusLine이나 Desktop 기록 수신값을 표시할 때만 나옵니다.
- 한 번도 연결하지 않은 Claude 프로필은 **연결 안 됨**으로 표시하고 **연결**을 안내합니다. 도움이 되지 않던 Desktop 로그인·새로고침 안내는 나오지 않습니다. 연결된 프로필의 버튼은 **연결 관리**로 표시합니다.
- 남은 양은 Cursor 한도를 포함해 모두 **남음**으로 표시합니다. Cursor 리셋 시각에는 이름표와 남은 시간을 붙이고, 모든 서비스가 확인 시각을 같은 **마지막 확인** 행으로 표시하며 오늘이 아닐 때만 날짜를 붙입니다.
- 사용량을 기다리는 동안 팝업은 링 옆 빈칸의 이유를 알려 주고, 계정 목록의 긴 안내는 한 줄로 줄입니다. Claude Desktop 기록 수신값은 한도마다 **제공되지 않음** 리셋 행을 두지 않고, 이 기록에는 리셋 시각이 없다고 한 번 안내합니다.
- 계정 관리, Claude 연결, 업데이트 창을 포함한 모든 창의 스크롤바가 어두운·밝은 테마를 따릅니다.
- 팝업에 릴리스 버전(**버전 0.6.5**)을 표시하고, 리셋권 버튼은 **리셋권 사용**으로 통일했습니다. Claude 연결 창의 Desktop 안내는 한 번만 표시하며, 위젯 링 안 글자를 키웠습니다.

Windows x64용 `CycleArc-Setup.exe`를 다운로드하세요. 기존 설치형 버전에서는 **업데이트 확인 → 업데이트 다운로드 → 재시작 후 적용**을 사용할 수 있습니다. 계정·설정·사용량 캐시는 `%LOCALAPPDATA%\ProMeter`에 유지됩니다.
