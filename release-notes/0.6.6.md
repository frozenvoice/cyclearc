# CycleArc 0.6.6

## Usage alert fixes

- When several limits need attention at once, the single notification now names every account and limit (up to what Windows can show, with the rest counted), and a click opens the most urgent account. Previously it described only one of them while treating all as announced.
- Each limit now alerts once per period as described. Usage that moves back and forth around 85% within the same period no longer repeats the alert; it re-arms only in a new period or after usage falls below 70%, such as after a reset without a reported time or a redeemed credit.
- A reported usage outside 0–100% is treated as unknown, as the rings already do: it never produces a "limit reached" alert and does not change what was already announced.

Download `CycleArc-Setup.exe` for Windows x64. Existing installed releases can use **Check for updates → Download update → Restart & update**. Accounts, preferences and quota caches remain in `%LOCALAPPDATA%\ProMeter`.

## 사용량 알림 수정

- 여러 한도가 한꺼번에 알림 대상이 되면, 알림 하나에 모든 계정과 한도를 적습니다(Windows가 보여 줄 수 있는 만큼 적고 나머지는 개수로 표시). 알림을 누르면 가장 급한 계정을 엽니다. 이전에는 하나만 설명하면서 전부 알린 것으로 처리했습니다.
- 안내대로 한도마다 기간당 한 번만 알립니다. 같은 기간에 사용률이 85% 근처를 오르내려도 다시 알리지 않으며, 새 기간이 시작되거나 사용률이 70% 아래로 내려간 뒤(리셋 시각 없는 초기화나 리셋권 사용 등)에만 다시 알립니다.
- 0~100%를 벗어난 사용률은 링과 같이 알 수 없는 값으로 처리합니다. **한도 도달** 알림을 보내지 않으며 이미 알린 기록도 바꾸지 않습니다.

Windows x64용 `CycleArc-Setup.exe`를 다운로드하세요. 기존 설치형 버전에서는 **업데이트 확인 → 업데이트 다운로드 → 재시작 후 적용**을 사용할 수 있습니다. 계정·설정·사용량 캐시는 `%LOCALAPPDATA%\ProMeter`에 유지됩니다.
