# CycleArc 0.10.1

## Installer and independent portable ZIP

- The first dual-format Windows x64 release offers `CycleArc-Setup.exe` and `CycleArc-0.10.1-win-x64-portable.zip` together. Both contain the same verified executable from the same source and version.
- The portable ZIP contains one self-contained `CycleArc.exe`, including the .NET 10 runtime. Extract it to a writable folder and run it in place without a separate .NET or CycleArc installation.
- Portable execution no longer installs itself. It skips Velopack initialization and managed updates, installation/tray registry migration and Windows startup registration. Tray, popup and widget remain available.
- Installed copies retain the existing Velopack update, repair, recovery and removal paths, optional desktop shortcut and opt-in Windows startup. Existing installed releases can use **Check for updates → Download update → Restart & update**. Full packages, update feed and checksums remain part of the release.
- Packaging and release checks compare the original publish, full-package and portable EXEs by SHA-256 and FileVersion, using evidence from the same exact Windows validation run. `SHA256SUMS.txt` includes the portable ZIP.
- Release validation requires managed startup consent, registration, execution of the actual registered Windows Run command, and opt-out removal. The registered command is tested directly on a disposable profile; this is not a real Windows logoff/logon test.

Portable and installed copies share accounts, preferences, quota caches and backups in `%LOCALAPPDATA%\ProMeter`. The first desktop in the current Windows session remains active. A shared data lock also prevents two new copies from writing these files in different sessions of the same Windows account. **0.10.0 and earlier do not honor that new lock: close older desktops in every session before switching versions or distributions.**

For a portable update, exit CycleArc, download the new ZIP, replace `CycleArc.exe` in the **same folder path**, then run it again. Passive Claude and Cursor callbacks can refer to that path; after moving or deleting the folder, reconnect the affected Claude integration or turn Cursor recent request off, apply, then on again. Portable users check Releases manually.

The public 0.10.0 release and all existing tags remain unchanged. Release artifacts remain unsigned unless code signing is configured.

## 설치형과 독립 포터블 ZIP

- Windows x64에서 두 배포 형식을 함께 제공하는 첫 릴리즈입니다. `CycleArc-Setup.exe`와 `CycleArc-0.10.1-win-x64-portable.zip`을 한 Release에 첨부하며, 두 파일은 같은 소스·버전의 검증된 실행 파일을 사용합니다.
- 포터블 ZIP에는 .NET 10 런타임을 포함한 단일 self-contained `CycleArc.exe`만 들어 있습니다. 쓰기 가능한 폴더에 압축을 풀고 그 자리에서 실행하며 별도 .NET 또는 CycleArc 설치가 필요 없습니다.
- 포터블 실행이 자신을 설치하던 동작을 제거했습니다. Velopack 초기화·관리형 업데이트, 설치·트레이 레지스트리 마이그레이션, Windows 자동 시작 등록을 수행하지 않습니다. 트레이·팝업·위젯은 그대로 사용할 수 있습니다.
- 설치형의 기존 Velopack 업데이트·복구·재설치·제거, 바탕화면 바로가기 선택 및 선택적 Windows 자동 시작을 유지합니다. 기존 설치형 버전에서는 **업데이트 확인 → 업데이트 다운로드 → 재시작 후 적용**을 사용하세요. Full package·업데이트 feed·체크섬도 함께 제공합니다.
- 패키징과 릴리즈 검증은 같은 정확한 Windows 검증 run의 원본 publish EXE·full package 내부 EXE·포터블 ZIP 내부 EXE의 SHA-256과 FileVersion을 비교합니다. `SHA256SUMS.txt`에 포터블 ZIP도 포함합니다.
- 릴리즈 검증에는 관리형 자동 시작의 사용자 동의·등록·실제 Windows Run 등록 명령 실행·동의 해제 후 등록 제거가 필요합니다. 폐기 가능한 프로필에서 등록 명령을 직접 실행하며, 실제 Windows 로그오프·재로그인 검증을 의미하지 않습니다.

설치형과 포터블은 `%LOCALAPPDATA%\ProMeter`의 계정·설정·한도 캐시·백업을 공유합니다. 현재 Windows 세션에서 먼저 실행된 데스크톱을 유지하며, 공용 데이터 잠금은 같은 Windows 계정의 다른 세션에서도 새 버전 두 개가 동시에 파일을 쓰지 못하게 합니다. **0.10.0 이하 버전은 새 잠금을 사용하지 않으므로 버전이나 배포 형식을 바꾸기 전에 모든 세션의 구버전 앱을 종료하세요.**

포터블 업데이트는 CycleArc를 종료하고 새 ZIP을 받은 뒤 **같은 폴더 경로**의 `CycleArc.exe`를 교체하고 다시 실행합니다. 수동 Claude 수신·Cursor 최근 요청 콜백이 해당 경로를 참조할 수 있으므로 폴더를 옮기거나 지운 뒤에는 해당 Claude 연결을 다시 연결하거나 Cursor 최근 요청을 끄고 적용한 뒤 다시 켜세요. 포터블은 Releases에서 새 버전을 직접 확인합니다.

기존 0.10.0 공개 릴리즈와 모든 기존 태그는 변경하지 않습니다. 코드 서명이 구성되지 않은 릴리즈 파일은 서명되지 않은 상태로 제공됩니다.
