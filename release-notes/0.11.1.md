# CycleArc 0.11.1

## Claude Desktop login detection and widget refresh fixes

- Fixed a yellow **Claude Desktop login required** warning that could remain even when Desktop was already signed in. CycleArc now recognizes Desktop's migrated Windows data location as well as the previous locations, so reconnecting the Claude CLI is not needed to repair this path mismatch.
- Fixed the widget losing its busy state when recreated during an active refresh after a display change, desktop recovery or position reset. The refresh button now stays busy until the shared refresh finishes, with the matching tooltip and accessible label.

Existing account identity checks and credential handling remain unchanged.

## Claude Desktop 로그인 감지와 위젯 새로고침 수정

- Claude Desktop에 이미 로그인했는데도 노란색 **Claude Desktop 로그인 필요** 경고가 남을 수 있던 문제를 수정했습니다. Desktop의 옮겨진 Windows 데이터 위치와 기존 위치를 함께 인식하므로, 이 경로 문제를 해결하기 위해 Claude CLI를 다시 연결할 필요가 없습니다.
- 새로고침 도중 화면 구성 변경, 데스크톱 복구 또는 위치 초기화로 위젯이 다시 만들어지면 조회 중 표시가 사라지던 문제를 수정했습니다. 공용 새로고침이 끝날 때까지 새로고침 버튼의 조회 중 상태와 툴팁·접근성 이름을 유지합니다.

기존 계정 신원 확인과 인증 정보 처리 방식은 유지됩니다.
